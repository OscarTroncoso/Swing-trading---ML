# forex-swingtrading — V3.2

EUR/USD daily swing-research project with a EUR-denominated account, trend-regime confirmation, structural/ATR stops, dynamic risk sizing and leakage-controlled validation.

## Current dashboard

The UI contains only the **current V3.2 model**. The old Google Sheets trade journal has been removed. `trades.html` displays only trades generated by V3.2.

## Run locally

```bash
pip install -r requirements.txt
pytest -q
python scripts/update_data.py --period 10y --backtest-start 2026-01-01 --out data.json --market-csv-out data/eurusd_daily.csv
python scripts/backtest_2026.py --csv data/eurusd_daily.csv --start 2026-01-01
python scripts/stop_diagnostics.py --csv data/eurusd_daily.csv --start 2026-01-01
```

Open `index.html` through a local web server or GitHub Pages.

## GitHub Actions

### `Tests`
Runs the automated anti-look-ahead/risk/ML tests.

### `Update EURUSD V3.2 dashboard`
Downloads one frozen OHLC dataset, updates `data.json`, runs the current backtest and stop diagnostics, and commits the outputs.

### `Full V3.2 research suite`
Runs:
- V3.1 benchmark vs V3.2 current
- stop MAE/MFE/false-stop diagnostics
- V3.2 component ablation
- sizing/stop/target attribution
- 243 structural/trend robustness combinations
- frozen annual walk-forward 2020–2026
- ML research-only walk-forward and feature tests

All research files are committed to `reports/` and also uploaded as a GitHub Actions artifact.

## Important files

- `src/strategy_engine.py` — V3.2 current engine
- `src/baseline_v31.py` — frozen benchmark used only for research comparison
- `src/ml_meta.py` — research-only ML challenger
- `config.json` — capital, risk, trend and stop settings
- `scripts/stop_diagnostics.py` — false-stop and excursion analysis
- `scripts/v32_ablation.py` — component attribution
- `reports/input-v3.1/` — reports supplied from the previous model
- `REPORT_DIAGNOSIS_V3_1.md` — why V3.2 was designed this way

Research software only; not financial advice or a broker execution system.
